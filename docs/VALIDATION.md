# 검증 기록

검증 환경: Node.js 24, Chromium, Playwright. 실제 금융 API·AI API는 검증 대상이 아닙니다.

- `npm test`: 4개 계산 테스트 통과. 총액 일치, 첫 달 특별 지출 단발 반영, 항목·결제수단 필터, 36개월 범위.
- `npm run build`: 성공. 외부 의존성·네트워크 요청 없는 정적 산출물 생성.
- Node 개발 서버 실행 및 Chromium 기능 검증 통과.
- 금융기관 동의/연결 → 소비 대시보드 이동.
- 신용/체크·혜택·적합도 필터 및 결과 없음 상태.
- 카드 상세 탭과 카드 선택 전환.
- 직접 12개월 설정 + 500,000원 예정 지출 → 월별 결과, 조건 재입력 시 유지.
- 추천 루틴 저장 후 새로고침 시 유지.
- 전월 비교 펼침, 카테고리 필터, 카드별 누락 리포트 필터.
- 모달 진입 및 Escape 닫기.
- 320×740, 375×812, 844×390, 1280×900에서 주요 11개 화면 가로 넘침 없음.
- 모션 감소 환경에서 렌더링, 브라우저 JavaScript 오류 0개.
- Figma 가져오기용 390px 너비 PNG 13개 생성.

재현: 개발 서버를 실행하고, Python Playwright 및 Chromium이 설치된 환경에서 `python3 tests/browser-smoke.py` 실행. Chromium 경로는 `/usr/bin/chromium`을 사용하므로 다른 OS에서는 변경이 필요합니다. 스크린샷은 다시 생성됩니다.

자동 접근성 인증이나 실사용 금융 테스트가 아닙니다. 스크린리더·실기기 전체 검증, 정식 금융 연동, 운영 배포는 별도입니다. GitHub Actions와 호스팅의 실제 배포 성공 여부는 해당 서비스에서 확인해야 합니다.
