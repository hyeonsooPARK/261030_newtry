# SOL AI 코치 · 소비 예측 & 카드 혜택 최적화

첨부된 서비스 기획안과 모바일 화면을 바탕으로 만든 **프론트엔드 인터랙티브 데모**입니다. HTML, CSS, JavaScript ES Modules로 구성했습니다. 외부 라이브러리·유료 API·비밀키 없이 실행됩니다. Figma 원본을 수정한 결과물이 아니라 첨부 화면을 참고하여 새로 작성한 코드입니다.

## 실행

Node.js 20 이상 설치 후 프로젝트 폴더에서:

```sh
npm run dev
```

터미널에 표시된 포트 5173으로 브라우저에서 접속합니다. `index.html`을 더블클릭하는 file:// 실행은 모듈 보안 정책 때문에 지원하지 않습니다.

```sh
npm test          # 예측 계산 모델 테스트 4개
npm run build    # dist/ 정적 사이트 생성
npm run preview  # dist/ 결과를 포트 4173으로 검증
```

의존성이 없으므로 `npm install`은 필요하지 않습니다. 현재 작업 폴더를 그대로 사용합니다.

## 구현한 흐름

- 홈 → AI 금융코치 → 금융 연결 수집·이용 안내 및 동의 → 가상 금융기관 연결 → 나의 소비
- 나의 소비 → 월 선택, 카테고리 필터, 전월 비교, 소비 항목 상세
- 보유 카드 → 신용/체크·특화 혜택·AI 적합도 필터 → 카드 선택 → 혜택 요약/실적 현황/카테고리 추천
- 카드 상세 → 놓친 혜택 리포트 → 카드별 필터 → 최적화 전략 → 우선 카드·추천 결제 루틴 로컬 저장
- 미래 소비 → 기간(1·3·6·직접 1~36개월), 특별 지출, 결제수단, 항목 선택 → 결과 → 목표 설정 → 맞춤 전략
- AI 종합 브리핑 → 각 항목의 분석 상세 화면
- 해시 기반 URL로 새로고침 및 직접 링크 지원, 모바일 하단 내비게이션, 브라우저 뒤로가기, 모달 Escape 닫기

## 데모와 실제 서비스의 경계

- 거래·금액·카드 조건·사용자명은 가상 데이터이며 2025년 10월을 고정 기준으로 사용합니다.
- 마이데이터·카드사 API·결제·카드 신청·LLM 호출은 연결하지 않았습니다. 실제 인증정보를 입력받지 않습니다.
- 예측은 `src/model.js`의 공개된 계산식입니다. 실제 AI 모델이나 금융 예측 정확도를 주장하지 않습니다.
- 특별 지출은 첫 달에 1회 반영, 기본 소비는 첫 달 +8%, 이후 매달 기준 소비의 2.5% 증가를 가정합니다. 신용/체크 비중은 92%/8%를 가정합니다.
- 누락 혜택 요약 24,500원 중 화면에 표시되는 대표 4건은 14,500원이며 기타 누락 10,000원이 포함됩니다.
- 브리핑은 템플릿 요약이고 절약액은 가상 시나리오입니다. 실제 약관과 혜택을 확인해야 합니다.
- 연결 상태·선택 기관·우선 카드·루틴만 브라우저 localStorage에 저장합니다. 외부 전송 없음. 전체 메뉴에서 초기화할 수 있습니다.

## GitHub 사이트에서 직접 업로드

1. 제공된 ZIP을 압축 해제합니다.
2. 본인 계정으로 `hyeonsooPARK/261030_newtry`에 로그인합니다.
3. **Add file → Upload files**에서 압축을 푼 폴더의 **내용물**을 올립니다. ZIP 자체나 상위 폴더를 올리지 마세요. `index.html`과 `package.json`이 저장소 최상위에 있어야 합니다.
4. `src`, `scripts`, `tests`, `docs`, `.github` 폴더까지 포함합니다. 숨김 폴더 `.github` 누락 시 자동 배포가 실행되지 않습니다.
5. README 변경을 포함해 커밋합니다. `node_modules`, `.git`, `dist`는 올릴 필요 없습니다.

## 배포

### GitHub Pages

저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택합니다. `main`에 업로드하면 포함된 workflow가 테스트·빌드·배포합니다. 이미 커밋된 상태라면 Actions 탭의 `Deploy prototype to GitHub Pages`에서 **Run workflow**를 실행합니다. 비공개 저장소의 Pages 지원은 계정 요금제에 따라 달라집니다. URL은 배포 성공 후 GitHub가 표시하는 주소를 사용하세요.

### Vercel

본인 GitHub 계정으로 Vercel에 로그인 → 저장소 Import → Framework `Other`, Build `npm run build`, Output `dist` → Deploy. 비밀키·환경변수는 필요하지 않습니다. `vercel.json`도 포함되어 있습니다.

### 정적 배포 ZIP

별도로 제공된 `sol-ai-coach-site.zip`을 해제하면 `index.html`과 `src/`가 최상위에 있습니다. 정적 호스팅의 업로드 배포에 사용할 수 있습니다.

## Figma 프로토타입

`docs/FIGMA-PROTOTYPE.md`에 화면별 연결과 설정을 기록했습니다. `docs/figma-screens`의 13개 PNG는 실제 구현 화면 캡처이며 Figma로 가져올 수 있습니다. PNG는 편집 가능한 벡터 프레임이 아니며 연결은 문서에 따라 Figma에서 설정해야 합니다. 원본 Figma 파일은 수정하지 않았습니다.

## 구조

- `src/app.js`: 화면 렌더링·해시 내비게이션·입력 검증·상태 관리
- `src/model.js`: 가상 데이터·예측 계산·금액 포맷
- `src/style.css`: 반응형 레이아웃·UI 토큰·접근성·모션 감소 대응
- `scripts/`: 의존성 없는 개발 서버와 정적 빌드
- `tests/`: 계산 모델 검증
- `docs/`: 화면 흐름, 캡처, 검증 기록

실서비스로 확장하려면 별도 백엔드, 정식 마이데이터 연동, 인증·동의 이력·삭제, 카드 약관 데이터, 검증된 예측 모델, 운영 보안 및 개인정보 처리가 필요합니다.
